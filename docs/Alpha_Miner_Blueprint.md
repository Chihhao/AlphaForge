# Alpha Miner（策略金鑰挖掘機）- 產品藍圖

> 最後更新：2026-03-15

---

## 1. 產品核心願景

AlphaForge 的最終演進目標是從「數據工具箱」轉變為「智慧投顧引擎」。

使用者不需要懂技術指標或寫程式，系統透過**邏輯迴歸因子模型**，自動從歷史數據中學出哪些因子組合能預測未來漲跌，並直接呈現量化的預期勝率。

> **核心設計原則：不要給使用者零件，要給使用者勝率。**
> 一個會說「我不確定」的系統，比一個永遠說「買！」的系統更值得信任。

## 2. 挖掘方法：邏輯迴歸因子模型

### 2.1 為什麼選邏輯迴歸，而不是其他方法

| 方法 | 說明 | 為何不選 |
|------|------|---------|
| 人工定義策略 | 人先猜，系統驗證 | 不是真正的挖掘，是 Validator 不是 Miner |
| Grid Search | 窮舉條件組合（AND 邏輯） | 無權重、無交互作用、搜索空間有限 |
| 遺傳演算法（GA） | 自動搜索條件組合 | 三條件以內用 Grid Search 就夠，四條件以上才需要 GA |
| 遺傳規劃（GP） | 自動生成任意數學公式 | 公式無法解釋，違背教育理念；需要大量運算資源 |
| 深度學習 / 強化學習 | 黑盒預測 | 無法向使用者解釋決策依據 |
| **邏輯迴歸** | 系統自動學出因子權重 | ✅ 選擇此方法 |

邏輯迴歸的優勢：
- 系統自動學出每個因子的**權重**，不需要人工指定
- 能捕捉**因子之間的交互作用**（例如 RSI + 量比同時出現比單獨出現更強）
- 自動處理**共線性**（RSI 和 KD 高度相關時，自動壓低其中一個）
- 結果**可解釋**：可以告訴使用者「這次訊號主要來自 RSI 和量比」

### 2.2 因子組合設計：為什麼不是真正的「自動挖掘」

目前 Alpha Miner 測試 **63 種預先設計的因子組合**（每個組合再跑 3 個持有期 = 189 個模型）。

這些組合是**人工挑選的**，基於投資邏輯（例如「RSI 超賣 + 量比放大」是有意義的組合），而非窮舉所有可能的排列。

**這和「自動挖掘」有何差別？**

| 方式 | 說明 | 優點 | 缺點 |
|------|------|------|------|
| 人工設計 63 組（現行） | 人工根據投資邏輯選定組合，系統學出權重 | 可解釋、不容易 p-hacking | 可能遺漏好組合 |
| FDR + 自動列舉 | 窮舉所有 k 因子組合，FDR 控制假發現率 | 理論上更完整 | 組合數爆炸（24 因子取 3 = 2,024 組）、信噪比差 |

**為什麼暫時不切換到 FDR + 自動列舉？**

自動列舉的問題不在統計方法，而在**信噪比**。數千個組合中，大多數沒有投資邏輯支撐，即使通過 FDR 也可能是噪音。目前系統的真正瓶頸是**因子庫太小**，而不是「搜索方式太保守」。

正確優先順序：**先擴充有意義的因子（Phase 6），再考慮更系統的搜索方式。**

### 2.3 模型設計

```
Y（因變數）= N 個交易日後收盤價 > 買入價 × (1 + threshold)
            （1 = 勝，0 = 否）

X（自變數）= 各因子的全市場分位數排名（0~1）
```

支援三種**持有期維度**（Phase 5A 完成）：

| 持有期 | 低門檻（tlo） | 高門檻（thi） |
|--------|------------|------------|
| 5 日   | 3%         | 5%         |
| 10 日  | 3%         | 5%         |
| 30 日  | 5%         | 10%        |

每個策略計算**兩套賠率比**：
- `odds_ratio` = `win_rate_outsample` / `loss_rate_outsample`（低門檻版）
- `odds_ratio_hi` = `win_rate_outsample_hi` / `loss_rate_outsample_hi`（高門檻版）

用**分位數排名**而非原始數值，原因：
- 符合邏輯迴歸的線性假設
- 消除不同股票、不同時期的量綱差異
- 例：RSI = 28 → 今日全市場 RSI 排名最低的 5% → 輸入 0.05

### 2.4 統計假設與應對

邏輯迴歸有四個統計假設，股市資料幾乎全部違反：

| 假設 | 現實 | 應對方式 |
|------|------|---------|
| 因變數二元 | ✅ 符合 | — |
| 線性關係 | 部分違反 | 改用分位數排名 |
| 觀測值獨立 | 違反（連續日期相關） | 訓練集與測試集之間留一個月空白 |
| 無嚴重共線性 | 違反（RSI/KD 相關） | 事先計算相關矩陣，標注共線因子 |

> **重要認知**：統計假設是理論理想，業界普遍知道股市資料違反這些假設，但仍廣泛使用邏輯迴歸，因為實務上效果穩定。我們用**樣本外驗證**來彌補假設不成立的問題——信心來自實證表現，不是統計假設。

## 4. 訓練資料設計

### 資料期間

使用 6 年歷史資料（FinMind 回補），加入**時間衰減權重**：

```
2025 年資料  → 權重 1.0（最重要）
2024 年資料  → 權重 0.8
2023 年資料  → 權重 0.6
2022 年資料  → 權重 0.4
2021 年以前  → 權重 0.2
```

原因：越舊的資料市場結構越不同（流動性、外資比重、散戶結構都在改變），不應與近期資料等權重。

### 訓練/測試切割

```
訓練集：2020-01 ~ 2024-12
空白期：2025-01（一個月，避免標籤洩漏）
測試集：2025-02 ~ 2026-03（完全未參與訓練）
```

> **為什麼要空白期**：預測目標是「N 日後漲跌」，如果訓練集最後一天是 12 月底，其標籤（N 日後）會延伸到 1 月，與測試集重疊造成資料洩漏。

## 5. 過擬合保護機制

### 5.1 樣本外驗證（主要防護）

```
模型在訓練集的勝率：62%
模型在測試集的勝率：57%   ← 這個才是真實能力
差距 < 5%               ✅ 可信
差距 > 5%               ⚠️ 疑似過擬合，標注警示
```

### 5.2 多重檢驗校正（Bonferroni）

測試多個因子組合時，純靠運氣也會出現假的顯著結果：

```
每個持有期測試 63 個因子組合
各維度獨立校正：顯著門檻 = 0.05 ÷ 63 ≈ 0.00079
只有 p < 0.00079 才算真正顯著（各維度獨立計算）
```

### 5.3 樣本數門檻

樣本數不足時，勝率數字沒有統計意義：

| 樣本數 | 需達到的勝率才顯著 | 處理方式 |
|--------|-----------------|---------|
| < 30 筆 | > 63% | 不顯示，標注「樣本不足」 |
| 30~80 筆 | > 59% | 顯示但標注「謹慎參考」 |
| > 500 筆 | > 54% | 正常顯示 |

## 6. 輸出與 UI 設計

### 策略頁面（strategy.tsx）

**Tab 切換**：5日 / 10日 / 30日（預設 10d）

**策略排行榜**（依測試集 IC 排序）：

```
策略名稱（自動命名）     漲跌3%              漲跌5%
                   賠率比 勝率 踩雷    賠率比 勝率 踩雷
──────────────────────────────────────────────────────
投信買超 5日累積     1.43x  31.8%  22.2%   1.51x  24.3%  16.1%
KD-K + 營收YoY      1.28x  28.5%  22.3%   1.15x  20.1%  17.5%
```

顏色語意：
- 賠率比 ≥ 1.2 → 琥珀色（強）；≥ 1.0 → 白色；< 1.0 → 紅色
- 勝率優於全市場基準 → 綠色；否則 → 紅色
- 踩雷率低於全市場基準 → 綠色；否則 → 紅色

**展開詳情**：
- 策略子標題（例：「『KD-K 動能 (-0.01)』與『年營收成長 (+0.34)』的多因子策略」）
- 樣本內 vs 樣本外勝率對比
- 兩門檻（tlo / thi）分欄比較
- 累積損益曲線
- 各因子的權重係數
- 近期觸發訊號列表

### 今日訊號頁（signals.tsx）

只使用 10d 顯著策略，訊號分層：
- 超強共鳴：≥ 20 個顯著策略同時看好

```

## 7. 誠信標注（重要）

以下情況系統必須主動標注：

- 樣本數 < 30：「樣本不足，結果不具統計意義」
- 樣本內外差距 > 5%：「此策略可能存在過擬合」
  > 註（2026-04-14）：此判定使用 `abs(wr_in - wr_out) > 0.05`，雙向皆觸發。實質是「樣本內外勝率不一致」的穩定性 heuristic，並非嚴謹 ML 定義的 overfit。20d/30d 維度常因 wr_out > wr_in 被標 ⚠，真因未確認；經多輪 review 決定暫不動，詳見 memory `project_overfit_flag_status.md`。
- 模型訓練至今已超過 30 天：「模型數據較舊，建議重新訓練」
- 所有勝率頁面底部：「AlphaForge 為學習型工具，勝率為歷史統計參考，不構成投資建議」

### 🔲 Phase 6：新因子擴充（下一步）

**外資持股比例變化**
- 來源：TWSE 外資持股統計
- 意義：持股比例連續增加 → 外資長期加碼，比單日買賣超更穩健
- 差異化：現有外資因子是「單日買賣超」，持股比例是「累積籌碼趨勢」

**產業相對強度**
- 計算方式：個股過去 20 日報酬率 - 同產業平均 20 日報酬率
- 意義：在強勢產業中選擇相對落後者（輪動機會）或相對強者（持續動能）
- 需要建立產業分類對照表（TWSE 產業代碼）

**執行順序**：
1. 新增資料管線（ETL）
2. 擴充 stock_features 欄位
3. 設計對應的新因子組合加入 63 組清單
4. 觸發全量重訓

### 🔲 Phase 7：Walk-Forward 滾動驗證（進階）

業界黃金標準，比單次訓練/測試切割更可靠：

```
第 1 折：訓練 2020-2022，測試 2023-Q1
第 2 折：訓練 2020-2023，測試 2024-Q1
第 3 折：訓練 2020-2024，測試 2025-Q1

優點：
- 模擬真實世界「只用過去資料預測未來」的情境

- 每折的 IC 分布可評估策略穩定性（非一次性僥倖）

## 9. 常見挑戰與回應

| 挑戰 | 我們的回應 | 信心來源 |
|------|-----------|---------|
| 過去有效不代表未來有效 | 測試集是模型完全沒見過的 2025~2026 資料 | 樣本外勝率 |
| 只有 6 年資料太短 | 涵蓋多頭、空頭、震盪三種市場環境，比單一牛市更有代表性 | 市場環境多樣性 |
| 統計假設違反，模型不可信 | 業界普遍知道假設被違反，仍廣泛使用，以實證補足 | 樣本外實證表現 |
| 測試這麼多因子一定有 p-hacking | Bonferroni 校正 + 樣本外驗證雙重防護 | 統計校正 + 實證 |
| 為什麼不窮舉所有因子組合？ | 瓶頸在因子品質，不在搜索廣度；先擴充有意義的新因子 | Phase 6 路線圖 |
| 散戶實際能獲利嗎？有交易成本 | AlphaForge 是學習型工具，勝率是參考指標，不是交易訊號 | 誠實說明使用限制 |
