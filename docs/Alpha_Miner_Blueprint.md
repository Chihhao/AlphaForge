# Alpha Miner (策略金鑰挖掘機) - 產品藍圖與 User Stories

## 1. 產品核心願景 (Vision)
AlphaForge 的最終演進目標是從一個「數據工具箱」轉變為一個「智慧投顧引擎」。
使用者不再需要自行摸索複雜的技術指標或寫程式碼，而是由系統透過**暴力窮舉與歷史數據回溯 (Back-tracing)**，自動挖掘出當前市場中「勝率最高」的公式金鑰，並直接提供量化的「明日上漲機率」與「兩週後勝率」。

---

## 2. 使用者故事 (User Stories)

### 🟢 2.1 初階使用者：數據導航模式 (Data Navigation)
*   **自動策略推薦**：身為量化投資新手，我希望能直接看到系統挖掘出的「今日前三強策略」，這樣我就不需要學習寫代碼，也能跟隨數據證明有效的邏輯選股。
*   **機率可視化**：身為短線交易者，我希望在每支股票旁看到「明日上漲機率：72%」，這能幫助我量化勝算，並決定投入資金的多寡。

### 🔵 2.2 進階使用者：策略鍛造模式 (Strategy Tuning)
*   **策略回溯稽核**：身為謹慎的投資者，我希望能點擊 AI 推薦的公式並查看其過去 3 年的歷史回測曲線 (Equity Curve)，以確認該勝率是穩定而非隨機的。
*   **自動閾值調優**：身為對策略有想法的使用者，我希望能給予系統一個指標方向（如：KD 金叉），讓系統自動幫我找出「在哪個數值範圍」對該支股票來說明日上漲勝率最高。

### ⚙️ 2.3 系統維度：自動化與可靠性 (Auto-Mining)
*   **Alpha 自動挖掘**：系統應在每日收盤數據同步後，自動在背景跑過萬種公式組合，即時更新每個策略的時效性。
*   **樣本外驗證 (Out-of-Sample Guardrail)**：系統必須確保挖掘出的公式能通過「未參與測試的數據」檢驗，以避免過度擬合 (Overfitting) 的無效規律。

## 3. 核心技術指標與定義

| 指標名稱 | 技術定義 | 應用價值 |
| :--- | :--- | :--- |
| **明日上漲機率 (Prob Tomorrow)** | 訊號觸發後的下一個交易日收盤價 > 觸發日收盤價的次數百分比。 | 作為超短線與當沖參考。 |
| **兩週後勝率 (2-Week Hit Rate)** | 訊號觸發後的第 10 個交易日價格高於買入價的百分比。 | 適合波段操作與一般精選策略。 |
| **期望報酬 (Expectancy)** | (平均獲利 * 勝率) - (平均虧損 * 敗率)。 | 衡量策略帶來的實際財富增長能力。 |
| **Alpha 分數** | 策略相對於大盤 (TAIEX) 的超額回報。 | 判斷此策略是否具備真正優於隨機選股的能力。 |

## 4. 實作路線圖 (Roadmap)

### Phase 1: 數據基礎補強 (Backend Core)
*   優化 `StockPrice` 歷史數據讀取。
*   實作按需補齊歷史價格 (On-demand yfinance Backfill)。
*   開發基礎 `BacktestService` 負責「訊號觸發日」的歷史對位。

### Phase 2: Alpha Miner 挖礦腳本 (Alpha Miner Engine)
*   建立具備 KD, RSI, MACD, Bias, Volume 等原子條件的計算庫。
*   實作「暴力窮舉器」：對符合篩選條件的股票，自動組合不同指標的閾值並記錄各週期的勝率。

### Phase 3: 前端機率整合 (UI/UX)
*   在 `Screener` 列表中加入「明日機率預估」標籤。
*   開發「策略掘金頁面」：展示當前市場勝率最高的 Top 3 公鑰。

### Phase 4: 樣本外驗證與個人化策略 (Advanced)
*   實作 Overfitting 保護機制。
*   開放 user 儲存自己的「黃金參數」。
