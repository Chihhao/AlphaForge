# 🚀 AlphaForge 學習日誌 - Day 09
**日期**：2026-03-10
**主題**：市場數據即時性修復與多維度選股濾網 (Volume Filter)

---

## 🧠 今日學習重點 (The "Why")

### 1. 數據源的「不可靠性」與備援邏輯
- **核心觀念**：本地計算的台灣大盤（^TWII）漲跌幅有時會因為開盤前的數據缺漏導致錯誤。實作「外部備援（Fallback）」機制，在本地數據不足時自動爬取 Yahoo Finance 官方收盤資料，是確保數據誠信的必要手段。

### 2. 選股維度的「量價與流動性」
- **實作心得**：純粹看基本面（成長性、ROE）選股雖然能選到優質公司，但若缺乏成交量支撐，會導致買不到或賣不掉。
- **解決方案**：在後端模型中引入 `volume_avg_5d`（5日均量），並將其作為「AF 精選」策略的強制濾網之一，確保篩選出的個股具備基本的交易流動性。

### 3. 使用者體驗細節：精確的「時間戳記」
- **心得**：在看板系統中，「何時更新」與「數據是什麼」一樣重要。新增 `refresh_date` 顯示，讓使用者明確知道目前的選股結果是基於哪一天的盤後數據，增加系統可靠感。

---

## 🏗️ 開發與維運成果

### ✅ 市場報價穩定性補強 [NEW]
- **大盤數據校準**：修復 TAIEX 指數漲跌幅與百分比計算錯誤。當本地資料庫無法算出前日收盤價時，自動從遠端 Yahoo Finance API 擷取官方參考值。
- **更新率優化**：微調市場數據元件的刷新頻率，平衡 Server 負載與前端即時性。

### ✅ 選股策略引擎升級 (Volume Engine)
- **模型擴展**：在 `StockFundamental` 模型中新增 `volume_avg_5d` 欄位，並實作跨表計算邏輯。
- **濾網實作**：將「5日均量 > 1000張」正式加入「AF 精選」策略，提升選股的實戰參考價值。

### ✅ 品牌與命名統一
- **策略名稱簡化**：應使用者要求，將 「AF 精選價值成長股」 更名為簡潔的 「AF 精選」，並將標籤更新為 「價值成長股」。
- **快取清理機制**：處理更名後前端快取殘留問題，確保所有介面顯示一致。
